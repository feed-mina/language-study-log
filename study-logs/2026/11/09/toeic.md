# TOEIC 800 Part 5: 장애 분석·운영 절차 실전 10문제

장애 분석과 운영 절차 문맥을 중심으로 동사 어휘, 형용사·부사, 미래완료 수동태, 전치사, 조건·대조 접속사, 관계대명사, 동명사, 수일치를 균형 있게 연습합니다.

## 전체 학습 항목

### 1. 문제

1. By comparing the application logs with the monitoring records, the engineers were able to ______ the source of the intermittent failure.
A. isolate
B. allocate
C. postpone
D. convene

- 정답: 정답: A. isolate — isolate the source of the intermittent failure
- 해설: isolate는 원인이나 문제 지점을 분리해 정확히 찾아낸다는 뜻으로 문맥에 맞습니다. allocate는 자원을 배정하다, postpone은 연기하다, convene은 회의를 소집하다는 뜻이라 source of the failure와 자연스럽게 결합하지 않습니다.

### 2. 문제

2. The revised checklist gives operators ______ instructions for responding to a network interruption.
A. clarity
B. clearly
C. clear
D. clearing

- 정답: 정답: C. clear — clear instructions
- 해설: 명사 instructions를 꾸미는 형용사가 필요하므로 clear가 정답입니다. clarity는 명사, clearly는 부사, clearing은 동명사·현재분사 형태로 이 자리에서 ‘명확한 지침’이라는 뜻을 만들지 못합니다.

### 3. 문제

3. By the time the security audit begins next Monday, all temporary access requests ______ by the compliance team.
A. review
B. reviewed
C. will have reviewed
D. will have been reviewed

- 정답: 정답: D. will have been reviewed — all temporary access requests will have been reviewed
- 해설: 미래 시점 전까지 완료될 동작이면서 requests가 검토를 받으므로 미래완료 수동태 will have been reviewed가 필요합니다. C는 능동태라 requests가 직접 검토한다는 잘못된 의미가 됩니다. A와 B는 시제와 문장 구조가 맞지 않습니다.

### 4. 문제

4. The database change must be carried out ______ accordance with the approved migration plan.
A. at
B. in
C. on
D. for

- 정답: 정답: B. in — in accordance with the approved migration plan
- 해설: in accordance with는 ‘~에 따라, ~에 부합하게’라는 고정 전치사 표현입니다. at, on, for는 accordance with 앞에 사용되지 않습니다.

### 5. 문제

5. The release will remain on hold ______ the unresolved data issue is addressed before noon.
A. unless
B. because of
C. despite
D. whereas

- 정답: 정답: A. unless — unless the unresolved data issue is addressed before noon
- 해설: ‘정오 전에 문제가 해결되지 않는 한 보류된다’는 조건이므로 unless가 적절합니다. because of와 despite는 뒤에 명사구가 필요하지만 빈칸 뒤에는 완전한 절이 옵니다. whereas는 두 사실을 대조할 때 쓰는 접속사입니다.

### 6. 문제

6. The consultant ______ recommendations were adopted will lead the implementation workshop.
A. who
B. whom
C. whose
D. which

- 정답: 정답: C. whose — the consultant whose recommendations were adopted
- 해설: recommendations와 consultant의 소유 관계를 나타내므로 소유격 관계대명사 whose가 필요합니다. who는 주격, whom은 목적격이며, which는 사물을 선행사로 받을 때 사용합니다.

### 7. 문제

7. The support team restored the service without ______ any active user sessions.
A. interrupt
B. interrupted
C. interrupting
D. interruption

- 정답: 정답: C. interrupting — without interrupting any active user sessions
- 해설: 전치사 without 뒤에는 명사 또는 동명사가 오므로 interrupting이 정답입니다. interrupt는 동사원형, interrupted는 과거형·과거분사입니다. interruption은 명사지만 뒤의 목적어 any active user sessions를 직접 취할 수 없습니다.

### 8. 문제

8. Neither the backup servers nor the main gateway ______ available during the maintenance window.
A. were
B. are
C. have been
D. was

- 정답: 정답: D. was — Neither the backup servers nor the main gateway was available
- 해설: neither A nor B의 동사는 가까운 주어 B에 일치시키므로 단수 main gateway에 맞춰 was를 씁니다. were와 are는 복수형이고, have been도 복수 주어에 맞는 형태입니다. maintenance window라는 과거 상황에도 was가 자연스럽습니다.

### 9. 문제

9. The analyst ______ documented each configuration change so that the rollback could be performed safely.
A. care
B. careful
C. carefully
D. carefulness

- 정답: 정답: C. carefully — carefully documented each configuration change
- 해설: 동사 documented를 꾸미는 부사가 필요하므로 carefully가 정답입니다. care와 carefulness는 명사, careful은 형용사이므로 동작 방식을 수식할 수 없습니다.

### 10. 문제

10. The test environment uses simulated traffic, ______ the production environment handles requests from actual users.
A. whereas
B. unless
C. because of
D. during

- 정답: 정답: A. whereas — whereas the production environment handles requests from actual users
- 해설: 두 환경의 차이를 대조하므로 접속사 whereas가 적절합니다. unless는 조건을 나타냅니다. because of와 during은 전치사이므로 뒤에 완전한 절을 직접 연결할 수 없습니다.
