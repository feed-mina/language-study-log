# 오늘의 실무 영어 5문장: 검증·후속 조치·안전한 변경

입력 형식 검증, 회의 후속 조치, 자동 복구 확인, 안전한 데이터 이전, 일정 변경 공유에 활용할 수 있는 자연스러운 실무 영어 표현을 연습합니다.

**대표 말하기 문장:** We can reduce the risk by testing the migration on a copy of the data first.

**대표 문장 뜻:** 먼저 데이터 복사본에서 이전 작업을 시험함으로써 위험을 줄일 수 있습니다.

## 전체 학습 항목

### 1. Before we automate this step, let's verify that the input format is consistent.

**뜻:** 이 단계를 자동화하기 전에 입력 형식이 일관적인지 확인합시다.

**설명:** Before + 주어 + 동사는 ‘~하기 전에’를 나타내고, verify that절은 확인할 내용을 덧붙입니다. verify는 ‘베러파이’, consistent는 ‘컨시스턴트’에 가깝습니다. 입력 데이터의 구조가 일정한지 먼저 점검하자고 제안할 때 사용합니다.

### 2. I'll capture the unresolved questions and assign each one a next action.

**뜻:** 해결되지 않은 질문을 정리하고 각각에 다음 조치를 지정하겠습니다.

**설명:** will은 즉석 결정이나 약속을 나타낼 수 있고, assign A B는 A에 B를 배정한다는 구조입니다. unresolved는 ‘언리졸브드’, assign은 ‘어사인’에 가깝습니다. 회의가 끝나기 전에 남은 논점과 후속 조치를 정리할 때 씁니다.

### 3. The service recovered automatically, but the delayed requests still need to be reviewed.

**뜻:** 서비스는 자동으로 복구됐지만 지연된 요청은 여전히 검토해야 합니다.

**설명:** recovered는 능동 과거형이고, need to be reviewed는 ‘검토될 필요가 있다’라는 수동 구조입니다. automatically는 ‘오터매티컬리’, reviewed는 ‘리뷰드’에 가깝습니다. 시스템이 회복된 뒤 남은 영향 범위를 확인해야 할 때 사용합니다.

### 4. We can reduce the risk by testing the migration on a copy of the data first.

**뜻:** 먼저 데이터 복사본에서 이전 작업을 시험함으로써 위험을 줄일 수 있습니다.

**설명:** by + 동명사 testing은 방법을 나타내고, on a copy of the data는 원본이 아닌 복사본을 시험 대상으로 삼는다는 뜻입니다. migration은 ‘마이그레이션’, reduce는 ‘리듀스’에 가깝습니다. 데이터 이전 전 안전한 시험 절차를 제안할 때 유용합니다.

### 5. If the deadline changes, please update the dependencies as well as the schedule.

**뜻:** 마감일이 바뀌면 일정뿐 아니라 의존 작업도 업데이트해 주세요.

**설명:** If + 현재형은 실현 가능한 미래 조건을 나타내며, A as well as B는 B뿐 아니라 A도 포함한다는 뜻입니다. dependencies는 ‘디펜던시즈’, schedule은 ‘스케줄’에 가깝습니다. 일정 변경이 연관 작업에 미치는 영향까지 함께 반영해 달라고 요청할 때 씁니다.
