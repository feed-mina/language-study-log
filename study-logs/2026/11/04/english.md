**설명:** separate A from B는 A와 B를 구분한다는 뜻입니다. confirmed는 ‘컨펌드’, assumptions는 ‘어섬션즈’에 가깝습니다. 회의나 장애 분석에서 검증된 정보와 아직 확인되지 않은 추정을 분리할 때 사용합니다.

### 2. The fix addresses the symptom, but it does not eliminate the underlying cause.

**뜻:** 이 수정은 증상을 해결하지만 근본 원인을 제거하지는 않습니다.

**설명:** address는 문제를 다루거나 완화한다는 뜻이고, eliminate는 완전히 제거한다는 뜻입니다. symptom은 ‘심프텀’, underlying은 ‘언더라잉’에 가깝습니다. 임시 수정과 근본 해결의 차이를 설명할 때 유용합니다.

### 3. Could we add an example to clarify how this option should be used?

**뜻:** 이 옵션의 사용 방법을 명확히 하기 위해 예시를 추가할 수 있을까요?

**설명:** Could we는 협업적인 제안이고, to clarify는 목적을 나타냅니다. how this option should be used는 평서문 어순의 간접의문문이자 수동태입니다. clarify는 ‘클래러파이’에 가깝습니다. 문서나 설정 안내를 개선할 때 씁니다.

### 4. I'll rerun the job with the same parameters to verify that the result is reproducible.

**뜻:** 결과를 재현할 수 있는지 확인하기 위해 같은 매개변수로 작업을 다시 실행하겠습니다.

**설명:** rerun은 다시 실행하다, with the same parameters는 같은 조건으로라는 뜻입니다. to verify는 목적을, is reproducible은 재현 가능함을 나타냅니다. parameters는 ‘퍼래미터즈’, reproducible은 ‘리프로듀서블’에 가깝습니다.

### 5. Once everyone has reviewed the draft, we can freeze the scope for this release.

**뜻:** 모두가 초안을 검토하고 나면 이번 릴리스의 범위를 확정할 수 있습니다.

**설명:** Once절의 has reviewed는 검토 완료를 강조하는 현재완료입니다. freeze the scope는 범위를 더 이상 변경하지 않도록 확정한다는 프로젝트 표현입니다. reviewed는 ‘리뷰드’, scope는 ‘스코프’에 가깝습니다.
