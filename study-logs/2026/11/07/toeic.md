# TOEIC 800 Part 5 실전 10문제: 서비스 용량과 출시 준비

서비스 용량 확장과 출시 준비 문맥에서 동사 어휘, 형용사·부사 구별, 현재완료 수동태, 원인 전치사, 조건 접속사, 관계대명사, 수일치, 동명사, 전치사 결합과 축약 관계절을 균형 있게 연습합니다.

## 전체 학습 항목

### 1. 문제

**문제**

1. The operations team upgraded the queue to ______ a higher volume of requests during peak hours.
A. convene
B. accommodate
C. expire
D. persuade

**정답**

정답: B. accommodate — accommodate a higher volume of requests

**해설**

accommodate는 용량·공간·시스템이 더 많은 수요를 ‘수용하다’라는 뜻으로, 요청량 증가에 대응하도록 큐를 업그레이드한 문맥에 맞습니다. convene은 회의를 소집하다, expire는 만료되다, persuade는 사람을 설득하다는 뜻이라 목적어와 문맥이 맞지 않습니다.

### 2. 문제

**문제**

2. The revised dashboard displays the performance metrics more ______ than the previous version.
A. clear
B. clarity
C. clearly
D. clearing

**정답**

정답: C. clearly — displays the performance metrics more clearly

**해설**

동사 displays를 꾸미고 비교급을 만드는 more 뒤에는 부사 clearly가 필요합니다. clear는 형용사, clarity는 명사, clearing은 동명사 또는 현재분사입니다. more clearly than은 ‘~보다 더 명확하게’라는 자연스러운 비교 표현입니다.

### 3. 문제

**문제**

3. Several inconsistencies ______ during the final review of the migration records.
A. have identified
B. were identifying
C. have been identified
D. identify

**정답**

정답: C. have been identified — Several inconsistencies have been identified

**해설**

불일치 항목은 식별하는 주체가 아니라 식별된 대상이고, 최종 검토 결과가 현재와 연결되므로 현재완료 수동태 have been identified가 맞습니다. A는 능동태라 주어와 맞지 않고, B는 과거진행 수동태가 아니며, D는 복수 현재형이지만 수동 의미가 없습니다.

### 4. 문제

**문제**

4. The rollout was delayed ______ a shortage of testing devices.
A. because of
B. unless
C. whereas
D. although

**정답**

정답: A. because of — because of a shortage of testing devices

**해설**

빈칸 뒤가 명사구 a shortage of testing devices이므로 원인을 나타내는 복합 전치사 because of가 필요합니다. unless, whereas, although는 접속사이므로 뒤에 주어와 동사가 있는 완전한 절이 와야 합니다.

### 5. 문제

**문제**

5. The team will extend the pilot ______ the error rate remains below the agreed threshold.
A. because of
B. despite
C. whereas
D. as long as

**정답**

정답: D. as long as — as long as the error rate remains below the agreed threshold

**해설**

as long as는 ‘~하는 한’이라는 조건 접속사로, 오류율이 기준 이하일 때만 시범 운영을 연장한다는 의미입니다. because of와 despite는 전치사라 뒤에 명사구가 필요합니다. whereas는 두 사실의 대조를 나타내므로 조건 문맥에 맞지 않습니다.

### 6. 문제

**문제**

6. The revised schedule, ______ was approved yesterday, includes an additional testing phase.
A. who
B. which
C. whose
D. where

**정답**

정답: B. which — The revised schedule, which was approved yesterday

**해설**

사물인 schedule을 선행사로 받고 관계절 안에서 주어 역할을 하므로 which가 맞습니다. 쉼표가 있어 계속적 용법입니다. who는 사람, whose는 소유격, where는 장소를 나타내므로 이 구조에 맞지 않습니다.

### 7. 문제

**문제**

7. Each of the proposed changes ______ a separate security review before deployment.
A. require
B. requiring
C. requires
D. have required

**정답**

정답: C. requires — Each of the proposed changes requires

**해설**

Each of＋복수명사는 전체 주어가 단수로 취급되므로 단수 동사 requires가 필요합니다. require는 복수형 동사, requiring은 분사라 문장의 본동사가 될 수 없습니다. have required는 복수형 현재완료이므로 단수 주어 Each와 일치하지 않습니다.

### 8. 문제

**문제**

8. The notification service checks the event ID to avoid ______ the same message twice.
A. send
B. sent
C. to send
D. sending

**정답**

정답: D. sending — avoid sending the same message twice

**해설**

avoid 뒤에는 동명사가 오므로 sending이 맞습니다. avoid to send 형태는 사용하지 않습니다. send는 동사원형, sent는 과거형·과거분사이며 이 자리에서 목적어 역할을 할 수 없습니다. 중복 알림 방지 문맥에도 자연스럽습니다.

### 9. 문제

**문제**

9. The release coordinator is responsible ______ verifying that all approval records are complete.
A. for
B. to
C. with
D. by

**정답**

정답: A. for — is responsible for verifying

**해설**

be responsible for＋명사·동명사는 ‘~을 담당하다’라는 고정 표현입니다. 따라서 verifying과 결합하는 전치사는 for입니다. responsible to는 보통 누구에게 책임을 진다는 의미일 때 쓰이며, with와 by는 이 표현에 맞지 않습니다.

### 10. 문제

**문제**

10. Customers ______ the beta version were asked to report any unexpected behavior.
A. use
B. used
C. using
D. uses

**정답**

정답: C. using — Customers using the beta version

**해설**

베타 버전을 사용하는 주체가 Customers이므로 능동 의미의 현재분사 using이 명사를 뒤에서 꾸밉니다. 이는 who were using 또는 who use가 축약된 형태로 볼 수 있습니다. used는 수동 의미가 되고, use와 uses는 이미 were asked라는 본동사가 있어 그대로 사용할 수 없습니다.
