# TOEIC 800 Part 5 실전 10문제: 장애 분석과 보고서 작성

장애 원인 분석과 보고서 작성이라는 실무 문맥에서 동사 어휘, 형용사·부사 품사, 미래완료 수동태, 양보 전치사, 조건 접속사, 소유격 관계대명사, 수일치, 전치사 뒤 동명사와 축약 수동절을 균형 있게 연습합니다.

## 전체 학습 항목

### 1. 문제

**문제**

1. The incident response team reviewed the server logs to ______ the exact sequence of events leading to the outage.
A. reconstruct
B. allocate
C. comply
D. postpone

**정답**

정답: A. reconstruct — reconstruct the exact sequence of events

**해설**

reconstruct는 흩어진 증거를 바탕으로 사건의 경과를 ‘재구성하다’라는 뜻이므로 로그를 검토해 장애 발생 순서를 파악하는 문맥에 맞습니다. allocate는 자원을 배정하다, comply는 규정을 준수하다라는 자동사로 보통 with가 필요하며, postpone은 일을 연기하다는 뜻입니다.

### 2. 문제

**문제**

2. The analyst provided a ______ explanation of why the processing delay occurred.
A. clarify
B. clarity
C. clearly
D. clear

**정답**

정답: D. clear — a clear explanation

**해설**

관사 a와 명사 explanation 사이에는 명사를 꾸미는 형용사 clear가 필요합니다. clarify는 동사, clarity는 명사, clearly는 부사이므로 이 위치에 올 수 없습니다. a clear explanation은 ‘명확한 설명’이라는 자연스러운 표현입니다.

### 3. 문제

**문제**

3. By the time the maintenance window ends tonight, all backup files ______ for integrity.
A. have verified
B. will have been verified
C. had verifying
D. are verify

**정답**

정답: B. will have been verified — all backup files will have been verified

**해설**

미래 시점인 tonight의 유지보수 종료 전까지 검증이 완료될 것이므로 미래완료가 필요하고, 파일은 검증을 받는 대상이므로 수동태 will have been verified가 맞습니다. A는 능동태라 주어와 맞지 않고, C와 D는 동사 형태가 문법적으로 성립하지 않습니다.

### 4. 문제

**문제**

4. ______ the unexpected network interruption, the support desk answered all urgent requests within an hour.
A. Despite
B. Although
C. Because
D. Unless

**정답**

정답: A. Despite — Despite the unexpected network interruption

**해설**

빈칸 뒤가 명사구 the unexpected network interruption이므로 전치사 Despite가 필요합니다. Although, Because, Unless는 접속사라 뒤에 주어와 동사가 있는 완전한 절이 와야 합니다. 문맥상 ‘예상치 못한 중단에도 불구하고’라는 양보 의미도 자연스럽습니다.

### 5. 문제

**문제**

5. The release will proceed on Friday ______ the final security review identifies no critical issues.
A. provided that
B. due to
C. despite
D. whereas

**정답**

정답: A. provided that — provided that the final security review identifies no critical issues

**해설**

provided that은 ‘~라는 조건으로’라는 조건 접속사이며 뒤에 완전한 절이 옵니다. 보안 검토에서 중대한 문제가 발견되지 않아야 배포한다는 문맥에 맞습니다. due to와 despite는 전치사라 명사구가 필요하고, whereas는 대조를 나타냅니다.

### 6. 문제

**문제**

6. The consultant ______ recommendations were adopted will lead the next phase of the project.
A. who
B. whose
C. whom
D. which

**정답**

정답: B. whose — the consultant whose recommendations were adopted

**해설**

recommendations가 consultant의 제안이라는 소유 관계이므로 소유격 관계대명사 whose가 필요합니다. who는 주격, whom은 목적격이며 뒤에 바로 명사를 소유 형태로 연결하지 못합니다. which는 사람인 consultant를 선행사로 받지 않습니다.

### 7. 문제

**문제**

7. Neither the revised checklist nor the supporting documents ______ available in the shared folder.
A. is
B. are
C. has
D. was

**정답**

정답: B. are — the supporting documents are available

**해설**

Neither A nor B 구조에서는 일반적으로 동사가 가까운 주어 B에 일치합니다. 가까운 주어 the supporting documents가 복수이므로 are가 맞습니다. is와 was는 단수 동사이고, has는 뒤의 available과 결합해 상태를 나타낼 수 없습니다.

### 8. 문제

**문제**

8. The engineering team reduced downtime by ______ the diagnostic scripts before the scheduled deployment.
A. run
B. ran
C. running
D. to run

**정답**

정답: C. running — by running the diagnostic scripts

**해설**

전치사 by 뒤에는 명사 또는 동명사가 와야 하므로 running이 맞습니다. by running은 ‘실행함으로써’라는 방법을 나타냅니다. run은 동사원형, ran은 과거형, to run은 부정사이므로 전치사 by의 목적어 자리에 사용할 수 없습니다.

### 9. 문제

**문제**

9. Users were notified ______ of the revised maintenance schedule.
A. prompt
B. promptly
C. promptness
D. prompted

**정답**

정답: B. promptly — were notified promptly

**해설**

수동태 동사 were notified를 꾸며 알림이 얼마나 신속하게 이루어졌는지 설명하는 부사 promptly가 필요합니다. prompt는 형용사 또는 동사, promptness는 명사, prompted는 과거분사이므로 이 부사 자리에 맞지 않습니다.

### 10. 문제

**문제**

10. The figures ______ in the quarterly report were independently verified before publication.
A. included
B. including
C. include
D. includes

**정답**

정답: A. included — the figures included in the quarterly report

**해설**

figures가 보고서에 ‘포함된’ 대상이므로 과거분사 included가 명사를 뒤에서 수식합니다. 이는 which were included가 축약된 수동 관계절입니다. including은 능동 의미, include와 includes는 본동사 형태인데 이미 문장의 본동사 were verified가 있어 사용할 수 없습니다.
