# 실무 영어 5문장: 회의 정리부터 업무 인계까지

회의 결론 정리, 요구사항 확인, 점진적 배포 관찰, 장애 상황 공유, 조사 내용 인계에 바로 사용할 수 있는 영어 표현을 연습합니다.

## 전체 학습 항목

### 1. 회의 결론 정리

**영어 문장**

Let me summarize the decisions and open questions before we move on.

**한국어 뜻**

다음으로 넘어가기 전에 결정 사항과 미해결 질문을 정리하겠습니다.

**설명**

문법: `Let me + 동사원형`은 자신이 어떤 일을 하겠다고 자연스럽게 제안할 때 사용합니다. 미래의 일을 나타내도 `before`절에는 현재형 `move`를 씁니다. 발음: `summarize`는 “서머라이즈”, `decisions`는 “디시전즈”에 가깝습니다. 사용 맥락: 회의의 한 주제를 마무리하며 결론과 남은 쟁점을 확인할 때 씁니다.

### 2. 필수 항목 확인

**영어 문장**

Could you clarify which fields are required and which are optional?

**한국어 뜻**

어떤 필드가 필수이고 어떤 필드가 선택 사항인지 명확히 설명해 주실 수 있나요?

**설명**

문법: `Could you clarify ...?`는 정중하게 설명을 요청하는 표현입니다. `which fields are required`는 의문사가 포함된 명사절이므로 평서문 어순을 사용합니다. 발음: `clarify`는 “클래러파이”, `required`는 “리콰이어드”, `optional`은 “옵셔널”에 가깝습니다. 사용 맥락: API, 입력 양식, 데이터 구조의 필수값과 선택값을 확인할 때 씁니다.

### 3. 점진적 배포 관찰

**영어 문장**

We'll monitor the key metrics during the gradual rollout.

**한국어 뜻**

점진적으로 배포하는 동안 핵심 지표를 관찰하겠습니다.

**설명**

문법: `will + 동사원형`은 앞으로 할 조치를 나타내며, `during + 명사`는 특정 기간 동안이라는 뜻입니다. 발음: `monitor`는 “마너터”, `metrics`는 “메트릭스”, `gradual rollout`은 “그래주얼 롤아웃”에 가깝습니다. 사용 맥락: 기능을 일부 사용자에게 먼저 공개하면서 오류율이나 응답 시간을 확인할 때 씁니다.

### 4. 장애 상황 공유

**영어 문장**

The service is stable again, but we're still investigating the underlying cause.

**한국어 뜻**

서비스는 다시 안정됐지만, 근본 원인은 아직 조사하고 있습니다.

**설명**

문법: `but`은 현재 복구 상태와 계속 진행 중인 조사를 대비합니다. `are investigating`은 지금 진행 중인 작업을 나타내는 현재진행형입니다. 발음: `stable`은 “스테이블”, `investigating`은 “인베스터게이팅”, `underlying`은 “언더라잉”에 가깝습니다. 사용 맥락: 서비스는 복구됐지만 원인 분석이 끝나지 않았음을 알릴 때 씁니다.

### 5. 조사 내용 인계

**영어 문장**

I've left detailed notes so the next person can continue without repeating the investigation.

**한국어 뜻**

다음 담당자가 조사를 반복하지 않고 이어갈 수 있도록 상세한 기록을 남겼습니다.

**설명**

문법: 현재완료 `I've left`는 기록을 남긴 결과가 현재도 유효함을 나타냅니다. `so + 주어 + can`은 목적이나 기대 결과를 설명하고, `without + 동명사`는 “~하지 않고”라는 뜻입니다. 발음: `detailed`는 “디테일드”, `continue`는 “컨티뉴”, `investigation`은 “인베스터게이션”에 가깝습니다. 사용 맥락: 교대 근무나 업무 인계에서 다음 담당자가 바로 이어서 조사할 수 있게 했다고 알릴 때 씁니다.
