# 실무 영어 5문장: 추정·재현·검토·위험·우선순위

개발 일정 추정, 오류 재현 조건, 검토 반영, 성능 위험 공유, 회의 우선순위 확인에 자연스럽게 사용할 수 있는 영어 표현 5개를 연습합니다.

## 전체 학습 항목

### 1번

**영어 문장:** Based on the current estimate, we should have a working version by tomorrow afternoon.

**한국어 뜻:** 현재 추정으로는 내일 오후까지 작동하는 버전을 준비할 수 있을 것입니다.

**설명:** 문법: Based on은 ‘~을 바탕으로’, should have는 가능성이 높은 예상을 나타냅니다. by는 완료 시한을 뜻합니다. 발음: Based on the는 ‘베이스톤 더’, working version은 ‘워킹 버전’처럼 이어 말합니다. 상황: 개발 일정이나 시제품 완료 예상 시점을 공유할 때 사용합니다.

### 2번

**영어 문장:** I can reproduce the issue only when two requests are submitted at the same time.

**한국어 뜻:** 두 요청이 동시에 제출될 때만 문제를 재현할 수 있습니다.

**설명:** 문법: only when은 ‘~할 때만’이라는 조건을 강조합니다. are submitted는 요청이 제출되는 것을 나타내는 수동태입니다. 발음: reproduce는 마지막 음절에 힘을 주어 ‘리프로듀스’, at the same time은 ‘앳 더 세임 타임’처럼 말합니다. 상황: 특정 동시 실행 조건에서만 오류가 나타난다고 설명할 때 사용합니다.

### 3번

**영어 문장:** I've addressed the review comments and pushed an updated version.

**한국어 뜻:** 검토 의견을 반영하고 업데이트된 버전을 올렸습니다.

**설명:** 문법: I've addressed와 (I've) pushed가 and로 연결된 현재완료 구조입니다. address comments는 의견이나 지적 사항을 처리한다는 뜻입니다. 발음: addressed는 ‘어드레스트’, pushed an은 ‘푸쉬턴’에 가깝게 연결됩니다. 상황: 코드나 문서 검토 의견을 반영한 뒤 변경본을 공유할 때 사용합니다.

### 4번

**영어 문장:** One concern is that this change may increase memory usage under heavy load.

**한국어 뜻:** 한 가지 우려는 이 변경으로 인해 부하가 높을 때 메모리 사용량이 증가할 수 있다는 점입니다.

**설명:** 문법: One concern is that 뒤에 우려의 내용을 완전한 절로 설명합니다. may는 가능성을 조심스럽게 제시합니다. 발음: concern은 두 번째 음절에 힘을 주어 ‘컨선’, memory usage는 ‘메머리 유시지’에 가깝습니다. 상황: 설계안이나 변경 사항의 잠재적 성능 위험을 객관적으로 공유할 때 사용합니다.

### 5번

**영어 문장:** Just to confirm, are we prioritizing reliability over delivery speed?

**한국어 뜻:** 확인차 여쭙는데, 저희는 전달 속도보다 안정성을 우선하고 있는 건가요?

**설명:** 문법: Just to confirm은 확인 질문을 부드럽게 시작하는 표현입니다. prioritize A over B는 ‘B보다 A를 우선하다’라는 뜻입니다. 발음: prioritizing은 ‘프라이오러타이징’, reliability는 ‘릴라이어빌러티’에 가깝습니다. 상황: 회의에서 상충하는 목표 사이의 우선순위를 명확히 확인할 때 사용합니다.

**대표 말하기 문장:** I can reproduce the issue only when two requests are submitted at the same time.
