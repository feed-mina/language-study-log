# 실무 영어 5문장 — 원인 분석·변경 분할·회귀 테스트

개발 및 회의 상황에서 데이터 불일치의 원인을 설명하고, 장애 대비 동작을 정하고, 변경을 작게 나누고, 남은 이견을 정리하며, 수정 후 회귀 테스트 필요성을 보고하는 영어 표현 5개를 연습합니다.

## 전체 학습 항목

### 1. 불일치 원인 설명

**The discrepancy appears to come from how missing values are handled.**  
이 불일치는 결측값을 처리하는 방식에서 발생하는 것으로 보입니다.

- 문법: appear to + 동사원형은 ‘~하는 것으로 보이다’라는 뜻입니다. how missing values are handled는 수동태가 포함된 명사절로 처리 방식을 나타냅니다.
- 발음: discrepancy는 ‘디스크레펀시’, handled는 ‘핸들드’에 가깝습니다.
- 상황: 수치나 결과가 서로 다른 원인을 조사한 뒤 유력한 원인을 조심스럽게 설명할 때 사용합니다.

### 2. 장애 대비 동작 정의

**Could we define a fallback behavior in case the external service is unavailable?**  
외부 서비스를 사용할 수 없는 경우에 대비해 대체 동작을 정의할 수 있을까요?

- 문법: Could we + 동사원형은 정중한 공동 제안입니다. in case + 문장은 ‘~할 경우에 대비해’라는 뜻입니다.
- 발음: fallback은 ‘폴백’, unavailable은 ‘어너베일러블’에 가깝습니다.
- 상황: 연동 서비스가 중단되더라도 기능이 어떻게 동작할지 미리 정하려고 할 때 사용합니다.

### 3. 검토 가능한 단위로 분할

**I'll break the task into smaller changes so each one is easier to review.**  
각 변경 사항을 더 쉽게 검토할 수 있도록 작업을 더 작은 단위로 나누겠습니다.

- 문법: break A into B는 ‘A를 B로 나누다’입니다. so + 주어 + 동사는 목적이나 결과를 나타냅니다.
- 발음: smaller는 ‘스몰러’, review는 두 번째 음절을 강하게 ‘리뷰’라고 말합니다.
- 상황: 큰 작업을 작은 커밋이나 검토 단위로 분리하겠다고 설명할 때 사용합니다.

### 4. 남은 이견 정리

**We haven't reached a consensus yet, so let's list the remaining concerns.**  
아직 합의에 이르지 못했으니 남아 있는 우려 사항을 정리해 봅시다.

- 문법: 현재완료 haven't reached는 지금까지 합의하지 못한 상태가 현재에도 이어짐을 나타냅니다. let's + 동사원형은 공동 제안입니다.
- 발음: consensus는 ‘컨센서스’, remaining은 ‘리메이닝’에 가깝습니다.
- 상황: 회의에서 결론을 서두르기보다 해결되지 않은 쟁점을 명확히 정리할 때 사용합니다.

### 5. 회귀 테스트 필요성 보고

**The fix has passed the targeted tests, but we still need a broader regression check.**  
수정 사항은 대상 테스트를 통과했지만, 더 광범위한 회귀 점검이 아직 필요합니다.

- 문법: 현재완료 has passed는 테스트 완료 결과가 현재 유효함을 나타냅니다. still은 추가 점검이 남았음을 강조합니다.
- 발음: targeted는 ‘타기티드’, regression은 ‘리그레션’에 가깝습니다.
- 상황: 특정 오류는 해결됐지만 다른 기능에 미친 영향을 확인하는 전체 검증이 남았다고 보고할 때 사용합니다.
