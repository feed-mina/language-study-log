# 실무 영어 5문장 — 진단·합의·작업 차단·점진적 공개·업무 인계

오류 원인 후보를 제거하는 표현, 회의에서 완료 기준을 합의하는 요청, 선행 변경으로 막힌 상태 보고, 제한된 대상부터 기능을 공개하는 계획, 후속 담당자를 위한 인계 기록 표현을 연습합니다.

대표 말하기 문장: **The logs point to a timing issue, but I want to rule out a configuration mismatch first.**  
한국어 뜻: 로그는 타이밍 문제를 가리키지만, 먼저 설정 불일치 가능성을 배제하고 싶습니다.

## 전체 학습 항목

### 1. 원인 후보 배제

**영어:** The logs point to a timing issue, but I want to rule out a configuration mismatch first.

**한국어:** 로그는 타이밍 문제를 가리키지만, 먼저 설정 불일치 가능성을 배제하고 싶습니다.

**설명:** 문법: point to는 ‘~을 가리키다’, rule out은 가능성을 ‘배제하다’라는 구동사입니다. 발음: configuration은 ‘컨피겨레이션’, mismatch는 ‘미스매치’에 가깝습니다. 상황: 로그가 한 원인을 시사하지만 다른 가능성도 먼저 확인하겠다고 말할 때 씁니다.

### 2. 완료 기준 합의

**영어:** Could we agree on the acceptance criteria before implementation begins?

**한국어:** 구현을 시작하기 전에 완료 기준에 합의할 수 있을까요?

**설명:** 문법: agree on은 ‘~에 합의하다’이고, 미래의 일을 말해도 before절에는 현재형 begins를 씁니다. criteria는 criterion의 복수형입니다. 발음: acceptance criteria는 ‘억셉턴스 크라이티어리아’에 가깝습니다. 상황: 개발 전에 무엇을 충족해야 완료로 인정할지 회의에서 정할 때 씁니다.

### 3. 작업 차단 상태 보고

**영어:** The task is blocked until the upstream change is available.

**한국어:** 선행 변경 사항이 준비될 때까지 이 작업은 진행할 수 없습니다.

**설명:** 문법: be blocked는 외부 요인 때문에 진행이 막힌 상태를 나타내며, until은 ‘~할 때까지’입니다. 발음: upstream은 ‘업스트림’, available은 ‘어베일러블’에 가깝습니다. 상황: 다른 작업이나 변경이 먼저 완료되어야 현재 작업을 진행할 수 있다고 보고할 때 씁니다.

### 4. 점진적 기능 공개

**영어:** We'll enable the feature for a small group before expanding access.

**한국어:** 접근 범위를 확대하기 전에 소규모 그룹을 대상으로 기능을 활성화하겠습니다.

**설명:** 문법: before 뒤의 expanding은 동명사이며, enable A for B는 ‘B를 대상으로 A를 활성화하다’라는 뜻입니다. 발음: enable은 ‘이네이블’, expanding은 ‘익스팬딩’에 가깝습니다. 상황: 위험을 줄이기 위해 기능을 제한적으로 먼저 공개할 때 씁니다.

### 5. 업무 인계 기록

**영어:** I've documented the current status, known risks, and next steps for the handoff.

**한국어:** 업무 인계를 위해 현재 상태, 알려진 위험 요소, 다음 단계를 문서로 정리했습니다.

**설명:** 문법: 현재완료 I've documented는 기록을 마쳤고 그 결과가 지금 인계에 유효함을 나타냅니다. 세 명사구가 and로 병렬 연결됩니다. 발음: documented는 ‘다큐멘티드’, handoff는 ‘핸드오프’에 가깝습니다. 상황: 다음 담당자에게 작업 현황과 남은 사항을 넘길 때 씁니다.
