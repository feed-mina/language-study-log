### 1. We have a likely explanation, but we still need evidence to confirm it.

### 2. Could you add a test that covers the case where the input is empty?

- 한국어 뜻: 입력값이 비어 있는 경우를 다루는 테스트를 추가해 주실 수 있나요?
- 설명: 문법: that covers는 test를 꾸미고, where the input is empty는 case의 구체적인 조건을 설명합니다. 발음: covers는 ‘커버즈’, input은 ‘인풋’, empty는 ‘엠프티’에 가깝습니다. 상황: 코드 리뷰에서 빈 값 같은 경계 사례의 테스트 보강을 요청할 때 씁니다.

### 3. Let's make sure the decision is reflected in both the plan and the acceptance criteria.

- 한국어 뜻: 그 결정 사항이 계획과 완료 기준 양쪽에 모두 반영되었는지 확인합시다.
- 설명: 문법: make sure 뒤에는 확인할 내용을 나타내는 절이 오며, both A and B는 두 대상을 함께 강조합니다. is reflected는 ‘반영되다’라는 수동태입니다. 발음: reflected는 ‘리플렉티드’, acceptance criteria는 ‘억셉턴스 크라이티어리아’에 가깝습니다. 상황: 회의에서 정한 내용을 계획서와 완료 기준에 일관되게 반영할 때 씁니다.

### 4. I'm going to pause the rollout until the error rate returns to normal.

- 한국어 뜻: 오류율이 정상으로 돌아올 때까지 배포 확대를 일시 중단하겠습니다.
- 설명: 문법: be going to는 결정한 계획을 나타내며, 미래 상황이어도 until절에는 현재형 returns를 씁니다. 발음: pause는 ‘포즈’, rollout은 ‘롤아웃’, returns는 ‘리턴즈’에 가깝습니다. 상황: 배포 중 지표가 나빠져 추가 확산을 멈추겠다고 알릴 때 씁니다.

### 5. If the same symptom appears again, we'll capture a trace before restarting the process.

- 한국어 뜻: 같은 증상이 다시 나타나면 프로세스를 재시작하기 전에 추적 정보를 수집하겠습니다.
- 설명: 문법: 미래 가능성을 말해도 if절에는 현재형 appears를 쓰며, before restarting은 ‘재시작하기 전에’라는 뜻입니다. 발음: symptom은 ‘심텀’, capture는 ‘캡처’, trace는 ‘트레이스’에 가깝습니다. 상황: 오류 재발 시 재시작으로 흔적이 사라지기 전에 진단 자료를 확보하겠다고 말할 때 씁니다.
