# 실무 영어 5문장: 마감·검토·변경 사항 전달

파일 요청, 검토 약속, 일정 변경 이유, 요구사항 준수, 후속 안내처럼 업무에서 자주 필요한 표현을 연습합니다.

## 전체 학습 항목

### 1. Please send me the updated file by noon.

- 한국어 뜻: 수정된 파일을 정오까지 보내 주세요.
- 문법: `send + 사람 + 사물`은 “사람에게 사물을 보내다”라는 구조입니다. `by + 시각`은 그 시각을 마감으로 하여 “늦어도 ~까지”라는 뜻입니다.
- 발음: `updated`는 “업데이티드”, `by noon`은 “바이 눈”처럼 말합니다.
- 사용 맥락: 상대방에게 파일이나 보고서를 특정 마감 시각까지 보내 달라고 정중하게 요청할 때 사용합니다.

### 2. I’ll review it as soon as I receive it.

- 한국어 뜻: 받는 즉시 검토하겠습니다.
- 문법: `as soon as`는 “~하자마자”입니다. 미래의 일을 말해도 시간 접속사 `as soon as` 뒤에는 `will receive`가 아니라 현재형 `receive`를 사용합니다.
- 발음: `I’ll review it`은 자연스럽게 이어서 “아일 리뷰잇”, `as soon as`는 “애즈 수너즈”에 가깝게 말합니다.
- 사용 맥락: 자료를 받으면 바로 확인하겠다고 약속할 때 사용합니다.

### 3. We postponed the release because additional testing was needed.

- 한국어 뜻: 추가 테스트가 필요했기 때문에 출시를 연기했습니다.
- 문법: `because + 주어 + 동사`는 이유를 나타내는 절을 연결합니다. `was needed`는 “필요했다”라는 수동태 표현입니다.
- 발음: `postponed`는 “포스트폰드”, `additional`은 “어디셔널”에 가깝게 발음합니다.
- 사용 맥락: 배포나 출시 일정이 바뀐 이유를 객관적으로 설명할 때 사용합니다.

### 4. We need to comply with the updated requirements.

- 한국어 뜻: 변경된 요구사항을 준수해야 합니다.
- 문법: `need to + 동사원형`은 “~할 필요가 있다”이고, `comply with + 규칙·요구사항`은 “~을 준수하다”라는 고정 표현입니다.
- 발음: `comply`는 두 번째 음절에 힘을 주어 “컴플라이”, `requirements`는 “리콰이어먼츠”에 가깝게 말합니다.
- 사용 맥락: 규칙, 표준 또는 새로 바뀐 요구사항을 따라야 한다고 설명할 때 사용합니다.

### 5. If anything changes, I’ll let you know right away.

- 한국어 뜻: 변경되는 것이 있으면 바로 알려 드리겠습니다.
- 문법: 실현 가능한 미래 조건은 `If + 현재형, 주어 + will`로 표현합니다. `let someone know`는 “누군가에게 알려 주다”라는 뜻입니다.
- 발음: `anything changes`는 “애니씽 체인지즈”, `right away`는 “라이터웨이”처럼 이어 말합니다.
- 사용 맥락: 일정, 작업 상태 또는 결정이 바뀌면 즉시 공유하겠다고 말할 때 사용합니다.
