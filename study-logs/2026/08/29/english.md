# 실무 영어 5문장: 오류 조사와 해결 방법 기록

오류가 지속된 기간을 설명하고, 검토를 요청하며, 발생 조건과 임시 해결 방법을 공유할 때 사용하는 영어 표현을 연습합니다.

## 전체 학습 항목

### 1. We’ve been monitoring the issue since this morning.

- 한국어 뜻: 오늘 아침부터 이 문제를 계속 모니터링하고 있습니다.
- 문법: `have been + 동사-ing`는 과거에 시작해 지금도 계속되는 행동을 나타냅니다. `since + 시작 시점`은 “~부터”라는 뜻입니다.
- 발음: `We’ve been`은 “위브 빈”, `monitoring the issue`는 “모니터링 디 이슈”에 가깝게 이어 말합니다.
- 사용 맥락: 오류나 장애를 언제부터 계속 관찰하고 있는지 진행 상황을 보고할 때 사용합니다.

### 2. The test has been running for two hours.

- 한국어 뜻: 테스트가 두 시간 동안 계속 실행되고 있습니다.
- 문법: `has been running`은 현재완료진행형입니다. `for + 기간`은 행동이 얼마나 오래 계속되었는지 나타냅니다.
- 발음: `has been running`은 “해즈 빈 러닝”, `for two hours`는 “퍼 투 아워즈”처럼 말합니다.
- 사용 맥락: 테스트, 배치 작업 또는 점검이 진행된 시간을 알릴 때 사용합니다.

### 3. The team requested that the change be reviewed before deployment.

- 한국어 뜻: 팀은 배포 전에 변경 사항을 검토해 달라고 요청했습니다.
- 문법: `request that + 주어 + 동사원형` 구조에서는 주어가 단수여도 동사원형을 씁니다. 변경 사항은 검토를 받는 대상이므로 수동태 `be reviewed`를 사용합니다.
- 발음: `requested that`은 “리퀘스티드 댓”, `be reviewed`는 “비 리뷰드”에 가깝게 발음합니다.
- 사용 맥락: 배포 전에 코드나 설정 변경을 검토하도록 공식적으로 요청했다고 설명할 때 사용합니다.

### 4. The issue only occurs under heavy load.

- 한국어 뜻: 이 문제는 부하가 높을 때만 발생합니다.
- 문법: `occur`는 “발생하다”라는 자동사이므로 목적어 없이 사용합니다. 단수 주어 `The issue`에 맞춰 `occurs`라고 씁니다.
- 발음: `occurs`는 두 번째 음절에 힘을 주어 “어커즈”, `heavy load`는 “헤비 로드”처럼 말합니다.
- 사용 맥락: 오류가 항상 발생하는 것이 아니라 특정 트래픽이나 처리량 조건에서만 재현된다고 설명할 때 사용합니다.

### 5. Let’s document the workaround before closing the ticket.

- 한국어 뜻: 작업 요청을 종료하기 전에 임시 해결 방법을 기록합시다.
- 문법: `Let’s + 동사원형`은 함께 행동하자는 제안입니다. `before + 동사-ing`는 “~하기 전에”라는 뜻이고, `workaround`는 근본 수정 전 사용하는 임시 해결 방법입니다.
- 발음: `Let’s document`는 “렛츠 다큐먼트”, `workaround`는 “워크어라운드”에 가깝게 발음합니다.
- 사용 맥락: 이슈를 닫기 전에 다른 사람이 재사용할 수 있도록 해결 절차를 남기자고 제안할 때 사용합니다.
