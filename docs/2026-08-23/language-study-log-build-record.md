# 영어·일본어·TOEIC 공부 기록 사이트 만들기

## 프로젝트 목적

매일 제공받는 영어·일본어·TOEIC 학습 자료를 중심으로 공부하고, 일정과 실제 학습 내용을 한곳에 기록하기 위한 개인 학습 대시보드를 만든다.

- 매일의 학습 일정 확인
- 학습 완료 여부와 공부 시간 기록
- 점수·성과·오답 메모 축적
- 영어 한 문장 말하기 음성 자료 제공
- 개인 기록은 Obsidian에 보관하고, 공유할 자료만 GitBook으로 발행

## 현재 확인할 수 있는 결과물

- 운영 사이트: <https://toeic-daily-study-log.minyerin.chatgpt.site/>
- GitHub 저장소: <https://github.com/feed-mina/language-study-log>
- 기본 브랜치: `main`
- 구현 이력: GitHub `main` 브랜치의 커밋 기록에서 확인

## 지금까지 완료한 과정

### 1. 학습 기록 사이트 제작

Next.js/React 기반으로 `TOEIC Daily` 대시보드를 만들었다.

현재 구현된 화면과 기능은 다음과 같다.

- 날짜별 학습 일정 조회 및 추가
- LC, RC, VOCA, TEST 분류
- 일정 완료·미완료 전환
- 공부 시간, 점수 또는 성과, 한 줄 메모 기록
- 최근 학습 기록 조회 및 삭제
- 주간 공부 일수와 달성률 표시
- 선택한 날짜의 총 공부 시간과 학습 개수 표시
- 모바일 화면을 포함한 반응형 UI

### 2. Cloudflare D1 연결

학습 일정과 학습 기록을 브라우저 안에만 저장하지 않고 Cloudflare D1 데이터베이스에 저장하도록 구성했다.

현재 테이블은 다음 두 개다.

- `study_plans`: 날짜별 계획, 분류, 제목, 세부 내용, 예상 시간, 완료 여부
- `study_logs`: 공부한 날짜, 파트, 제목, 공부 시간, 점수, 메모

API는 일정·기록 조회, 추가, 완료 상태 변경, 기록 삭제를 지원한다.

### 3. 사이트 배포

Sites를 통해 웹사이트를 배포했으며, 현재 공개 주소에서 접속할 수 있다. 소셜 공유용 메타데이터와 대표 이미지도 추가했다.

### 4. GitHub 저장소 연결

사이트 소스 코드를 `feed-mina/language-study-log` 저장소의 `main` 브랜치에 올렸다. 사이트 코드와 데이터베이스 스키마를 Git으로 관리할 수 있는 상태다.

### 5. 학습 자동화 방향 정리

예약 일정과 연계하여 다음 흐름을 구상했다.

1. 아침에 영어·일본어·TOEIC 학습 자료 생성 또는 수집
2. 이메일이나 알림으로 오늘의 학습 자료 전달
3. 영어 한 문장 말하기에는 음성 파일 함께 제공
4. 전달받은 자료로 공부한 뒤 사이트에 결과 기록
5. 하루 기록을 Markdown으로 만들어 Obsidian에 보관
6. 공개할 내용만 별도 폴더를 통해 GitBook에 공유

## 2026-08-23 자동화 API 구현 업데이트

사이트 Worker 엔트리에 자동화 API와 예약 실행기를 추가했다.

- `GET /api/health`, `GET /api/materials`, `GET /api/assets/:id`
- Bearer 토큰으로 보호되는 자료 생성·재발송·파일 업로드 API
- 매일 06:30 영어, 08:00 일본어, 월–토 18:00 TOEIC Cron 설정
- Workers AI 학습 콘텐츠 생성 및 영어 첫 문장 MP3 생성 코드
- D1 콘텐츠·파일 메타데이터·발송 이력·자동화 실행 이력 테이블
- R2 MP3/PDF/이미지 저장과 20 MiB 업로드 제한
- Email Service 본문/HTML/MP3 첨부 발송 및 중복 발송 방지
- GitHub Actions 검사와 Cloudflare 자동 배포 워크플로

로컬에서는 빌드, 타입 검사, 린트, D1 마이그레이션, Worker 배포 dry-run, API 인증, R2 업로드·다운로드를 검증했다. 실제 Workers AI 생성, 실제 이메일 수신, Cron 운영 실행은 Cloudflare 로그인과 리소스·비밀 값 설정 후 확인해야 한다.

## 권장 데이터 흐름

```text
예약 실행
  ↓
영어·일본어·TOEIC 학습 자료 생성
  ↓
D1: 일정과 학습 상태 저장
R2: 음성·PDF·이미지 저장
  ↓
이메일/알림으로 오늘 자료 전달
  ↓
사이트에서 공부 완료와 메모 기록
  ↓
비공개 Obsidian Markdown 생성
  ↓ 사용자 검토·승인
공유용 문서만 GitBook에 발행
```

## Obsidian과 GitBook 연결 원칙

- Obsidian Vault에는 개인 공부 기록, 점수, 오답과 회고를 보관한다.
- GitBook에는 사용자가 직접 공유하기로 승인한 자료만 올린다.
- 비공개 Vault 전체를 GitBook과 바로 동기화하지 않는다.
- `publish: true`로 승인된 문서 또는 별도의 `publish/` 폴더만 공유 대상으로 삼는다.
- 음성 파일은 기본적으로 비공개 R2에 두고, 공개 승인한 파일만 공개한다.
- 자동화는 같은 파일을 여러 시스템이 동시에 수정하지 않도록 단방향 생성과 검토 절차를 사용한다.
